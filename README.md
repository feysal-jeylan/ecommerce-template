\# Mobile-First E-Commerce Template

A clean, responsive e-commerce template built with \*\*mobile-first approach\*\* using pure HTML, CSS, and JavaScript.

\- 👨‍💼 \*\*Admin Dashboard\*\* - Simple admin interface
